## Что нового в 0.1.0 — коротко

- **Автотипограф** — выделил текст → R⌥+Backspace → текст превращается в типографски правильный (кавычки-ёлочки, тире, неразрывные, валюта и т.д.). Полный паритет с Windows-версией.
- **Ёфикатор** — словарь на 3018 словоформ, по желанию вместе с типографом проставляет «ё» там, где должна быть «ё». Включается отдельным пунктом меню.
- **Единый формат раскладки с Windows** — теперь `config.ini` вместо `config.json`. Файл с одного компьютера переезжает на другой без конвертации — даже между macOS и Windows.
- **Авто-перезагрузка настроек** — подменили `config.ini` снаружи (например, синхронизация через облако) — программа подхватит без перезапуска.
- **Буфер обмена не теряется** — раньше при вставке символа-пробела картинка/RTF в буфере убивались, теперь сохраняется и восстанавливается весь буфер целиком.
- **Меню стало понятнее** — переименовали пункты, добавили «Ёфикатор», убрали то, что не работало.
- **Внутрянка** — программа переписана по этапам, стала меньше и предсказуемее. Логи через `os.Logger`, в release-сборке не шумят.

## Автотипограф — главная новая фишка

### Как пользоваться

1. Выделили любой кусок текста (где угодно — TextEdit, Safari, Telegram, Figma…).
2. Нажали **правый ⌥Option + Backspace**.
3. Выделение заменилось на типографски правильную версию.

В правом нижнем углу всплывает короткая подсказка-плашка:
- «Типографировано ✓» — текст изменили.
- «Уже типографировано ✓» — менять было нечего (вставка не дёргается).
- «Выделите текст» — выделение было пустым, буфер обмена цел.

> Сочетание **правый ⌥Option + Backspace** — параллель с Windows-версией (там это RAlt+Backspace). Конфликт с системным «удалить слово» не возникает: перехватывается только **правый** ⌥, на левый ⌥+Delete программа не реагирует, и «удалить слово» по-прежнему работает.

### Что делает типограф

Конвейер по группам правил (порядок жёсткий, чтобы результат не зависел от настроения):

- **Кавычки** — `"..."` → `«...»`, вложенные — `„..."`. Дюйм после числа (`Монитор 21"`) — не трогает. Апостроф в латинице (`d'Artagnan`, `it's`) — превращает в `’`. macOS-«умные кавычки» `“…”`, которые TextEdit и браузеры подставляют автоматически, нормализуются в «ёлочки».
- **Тире** — `--`, `–`, `-` между словами → длинное `—` (с неразрывным пробелом перед ним). Прямая речь в начале строки — то же самое. Диапазоны `2002-2009`, римские `XI-XII` — среднее тире `–` без пробелов. Даты `12-05-2024` и слова `кто-то`, `по-русски` — не трогаются.
- **Пунктуация и многоточие** — `...` → `…`, `!?` → `?!`, повторы знаков схлопываются.
- **Чистка пробелов** — двойные пробелы, пробелы у скобок и перед знаками препинания, обязательный пробел после `,;:` перед буквой. Десятичные дроби и время — не страдают.
- **Числа и валюта** — `109 руб.` → `109 ₽`, `USD/EUR/RUB` → `$/€/₽`. Разряды от 5 цифр группируются неразрывными пробелами **только** в валютном контексте (`2 345 123 ₽`), версии вида `2.5.1` не разваливаются. Десятичная точка в валюте → запятая. Копейки сливаются в дробь: `45 руб. 5 коп.` → `45,05 ₽`.
- **Неразрывные пробелы** — `5 лет`, инициалы `А. А. Иванов`, частицы (`б`, `бы`, `ж`, `же`, `ли`, `ль`), короткие предлоги/союзы (≤3 букв). Чтобы строка не разрывалась там, где не должна.
- **Символы** — `(c)` → `©`, `(r)` → `®`, `(tm)` → `™`, `+-` → `±`, `№` слипается с числом неразрывным пробелом.

Правила идемпотентны: прогнать типограф дважды по одному тексту = прогнать один раз. На уже типографированном тексте показывается «Уже типографировано ✓» и буфер обмена даже не трогается.

### Ёфикатор

Отдельный тумблер в меню — **«Ёфикатор»**. Если включён, перед типографом по словам пробегается мини-словарь однозначных е-форм и подменяет на ё-форму:
- `елка` → `ёлка`, `ежик` → `ёжик`, `еще` → `ещё`, …
- Регистр сохраняется: `Елка` → `Ёлка`, `ЕЛКА` → `ЁЛКА`.
- Только однозначные случаи — никакого угадывания «всё/все», «осёл/осел».

Словарь — ресурс `yodict.txt` в составе приложения, 3018 парадигм (подмножество eyo-kernel, MIT).

## Новый формат раскладки — `config.ini`

### Что поменялось

- Файл настроек теперь называется **`config.ini`** (был `config.json`).
- Лежит там же: `~/Library/Containers/hypetype.hypetype/Data/Library/Application Support/hypetype/`.
- Формат — простой и читаемый человеком, **совместимый с Windows-версией один-в-один**.

### Миграция со старого формата

При первом запуске 0.1.0:
- Если найден старый `config.json` и нет `config.ini` — раскладка автоматически переедет в новый файл.
- Старый файл переименовывается в `config.json.old` (бэкап, не удаляется).
- Эмодзи и многокодпоинтные значения переезжают корректно (конвертация по Unicode scalars, а не по графемам).

### Перенос между устройствами

Просто скопируйте `config.ini` на другой компьютер. **macOS ↔ Windows работает в обе стороны** — это и было целью.

### Авто-перезагрузка

Подменили `config.ini` снаружи (рукам, скриптом, облачной синхронизацией) — программа заметит и подхватит новую раскладку без перезапуска. Перезапуск больше не нужен.

### Секция `[macOS]`

В файле теперь есть платформенная секция с параметрами. Сейчас читается:
- `DiacriticTimeoutMs` — таймаут ожидания символа в режиме диакритики, мс. По умолчанию 3000.

## Что починилось «незаметно» по дороге

- **Буфер обмена.** Раньше, если в буфере лежала картинка или форматированный текст (RTF), вставка символа-пробела через программу буфер уничтожала. Теперь сохраняется и восстанавливается **весь** буфер целиком — все типы данных, не только строка.
- **Логи.** Все `print()` заменены на `os.Logger`. В release-сборке отладочные записи молчат сами, ничего настраивать не надо.
- **Внутренний порядок.** Программа разложена на модули, дубли убраны, мёртвый код вычищен. Для пользователя ничего не меняется, для багов меньше места жить.

<br>

## Известное ограничение (не наш баг)

Ударение над кириллицей (`а́` = буква + U+0301) на macOS 26.5 визуально не «садится» на букву. Воспроизводится и на старой сборке программы, и в раскладке Бирмана — это изменение рендеринга combining-знаков в самой ОС, а не регрессия в hypetype. Технически программа отдаёт корректный Unicode; чинить мутацией кодпоинтов нельзя — это сломает корректную работу в других ОС и шрифтах. Перепроверим на следующих апдейтах macOS.
