## 🎯 Основные файлы проекта

### 1. **hypetypeApp.swift** (МОДИФИЦИРОВАН)
Главный файл приложения:
- `@main` точка входа
- `AppDelegate` с menu bar интеграцией
- Управление разрешениями Accessibility
- `SettingsView` для настроек

**Что делает:**
- Создает иконку в menu bar
- Запрашивает разрешения
- Управляет EventTapManager
- Показывает меню с настройками

---

### 2. **EventTapManager.swift** (СОЗДАН)
Ядро системы перехвата:
- CGEventTap для перехвата клавиш
- **Правильное определение правого Option** (keyCode 0x3D)
- Отслеживание состояния Shift
- 4 тестовых маппинга для проверки

**Класс SymbolInserter:**
- Два метода вставки (clipboard / direct)
- Сохранение и восстановление буфера обмена
- Unicode вставка

**Тестовые символы:**
```
Right Option + [  →  «  (левая кавычка)
Right Option + ]  →  »  (правая кавычка)
Right Option + -  →  –  (короткое тире)
Right Option⇧ + - →  —  (длинное тире)
Right Option + .  →  …  (многоточие)
```

---

### 3. **SettingsManager.swift** (СОЗДАН)
Управление настройками:
- `ObservableObject` для реактивности
- Сохранение в UserDefaults
- Две настройки:
  - `isEnabled` - вкл/выкл перехвата
  - `useClipboardMethod` - метод вставки

---

### 4. **KeyCodes.swift** (СОЗДАН, опциональный)
Справочник key codes:
- Все буквы (A-Z)
- Все цифры (0-9)
- Символы ([], -=, etc.)
- Модификаторы
- Extension для удобства

**Использование:**
```swift
0x21.keyName  // "["
```

---

### 5. **Info.plist** (СОЗДАН)
Настройки приложения:
- `LSUIElement = true` - menu bar режим
- Описания разрешений для пользователя
- Минимальная версия macOS 13.0+

## 🧪 Как тестировать

### Этап 1: Базовая проверка (5 минут)
1. Открыть проект в Xcode
2. Настроить Info.plist
3. Добавить Hardened Runtime
4. Build (⌘B)
5. Run (⌘R)
6. Дать разрешения Accessibility

### Этап 2: Проверка перехвата (2 минуты)
1. Открыть Console.app
2. Фильтр: "hypetype"
3. Нажать Right Option
4. Должно быть: `🔵 Right Option нажат`
5. Нажать Left Option
6. Ничего не должно быть ✅

### Этап 3: TextEdit (3 минуты)
Попробовать все 5 комбинаций:
- ⌥ [ → «
- ⌥ ] → »
- ⌥ - → –
- ⌥⇧ - → —
- ⌥ . → …

### Этап 4: Figma (5 минут)
Те же комбинации в Figma Desktop или Web

### Этап 5: Adobe (5 минут)
Если есть - проверить в Photoshop/Illustrator

## 📝 Важные замечания

### Про правый Option
- Определяется через keyCode **0x3D (61)**
- Отслеживается через `flagsChanged` события
- **Надежный метод** - работает на всех клавиатурах

### Про методы вставки
- **Clipboard** (по умолчанию):
  - Работает везде
  - Временно меняет буфер (150ms)
  
- **Direct**:
  - Не трогает буфер
  - Может не работать в некоторых приложениях

### Про логирование
Все логи с эмодзи для удобства:
- ✅ успех
- 🔵 детекция Option
- ⌨️ перехват клавиши
- 📋 вставка clipboard
- ⚡ вставка direct
- ❌ ошибка
- ⚠️ предупреждение

## 🆘 Если что-то пошло не так

### Первая помощь
1. Проверьте **CHECKLIST.md** - все ли шаги выполнены
2. Откройте **TROUBLESHOOTING.md** - там решения
3. Смотрите логи в Console.app
4. Попробуйте перезапустить приложение

### Типичные проблемы
- **Файлы не видны в Xcode** → Добавьте вручную через "Add Files"
- **Не компилируется** → Проверьте Target Membership
- **Event Tap не запускается** → Проверьте разрешения Accessibility
- **Левый Option тоже срабатывает** → Ошибка в коде определения
