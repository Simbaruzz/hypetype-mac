## 💡 Советы по использованию

### Диакритика
1. Нажмите комбинацию с диакритическим знаком (например ⌥⇧ V для гачека ̌)
2. Система перейдёт в режим ожидания
3. Нажмите букву (например g)
4. Получится ǧ (g с гачеком)

### Часто используемые
- **Кавычки**: ⌥ , и ⌥ . для « »
- **Тире**: ⌥ - для длинного —
- **Многоточие**: ⌥ / для …
- **Copyright**: ⌥ C для ©
- **Trademark**: ⌥ T для ™
- **Евро**: ⌥ E для €
- **Рубль**: ⌥ H для ₽

### Математика
- **Умножить**: ⌥ X для ×
- **Приблизительно**: ⌥ A для ≈
- **Не равно**: ⌥ = для ≠
- **Градус**: ⌥ D для °
- **Бесконечность**: ⌥ 8 для ∞
