## 🚀 Быстрый старт

### Что делать если клавиши залипли ПРЯМО СЕЙЧАС:

1. **Кликни на иконку** `⌥` в menu bar
2. **Выбери** `🔄 Сбросить состояние` (или нажми ⌘R)
3. **Нажми OK** в диалоге
4. **Готово!** Клавиши должны заработать

### Как включить логи для отладки:

1. **Кликни на иконку** в menu bar
2. **Включи** `🔍 Отладочные логи` (поставь галочку)
3. **Открой Console.app** (⌘+Space → Console)
4. **Фильтр:** `hypetype`
5. **Печатай символы** и смотри логи в реальном времени

## 🔧 Что было исправлено?

### Проблема

**Залипание правого Option после быстрой печати:**

```
1. Нажимаю Right Option + H несколько раз быстро
2. Отпускаю Right Option
3. Нажимаю A → получаю символ ≈ вместо буквы a ❌
4. Другие клавиши (не из маппинга) вообще не работают
```

### Причина

**Пропуск события `flagsChanged` во время вставки символа:**

- При быстрой печати символ вставляется (`isInserting = true`)
- В это время приходит событие "Right Option отпущен" (`flagsChanged`)
- Событие пропускается (из-за `if isInserting { return }`)
- Флаг `rightOptionPressed` остаётся `true` навсегда 💥

### Решение

**5 уровней защиты от залипания:**

1. ✅ **Обработка `flagsChanged` ДО проверки `isInserting`**
   - Флаги модификаторов обновляются ВСЕГДА
   - Даже во время вставки символа

2. ✅ **Принудительная синхронизация при каждом `keyDown`**
   - Проверяем реальное состояние модификаторов из события
   - Если рассинхронизировались — исправляем на лету

3. ✅ **Автоматический сброс через таймер (5 секунд)**
   - Если `rightOptionPressed = true` уже 5+ секунд без активности
   - Автоматический сброс всех флагов

4. ✅ **Ручной сброс через меню (⌘R)**
   - Пункт меню "🔄 Сбросить состояние"
   - Мгновенный сброс всех флагов

5. ✅ **Подробный логгер для отладки**
   - Все события клавиатуры в Console.app
   - Переключатель в меню "🔍 Отладочные логи"

```diff
+ // ✅ Обработка flagsChanged ПЕРВЫМ (до isInserting)
+ if type == .flagsChanged {
+     if keyCode == 0x3D {
+         rightOptionPressed = flags.contains(.maskAlternate)
+     }
+     return Unmanaged.passRetained(event)
+ }

+ // ✅ Принудительная синхронизация
+ let actualRightOptionPressed = event.flags.contains(.maskAlternate)
+ if actualRightOptionPressed != rightOptionPressed {
```

## 🧪 Как тестировать?

### Быстрый тест (1 минута)

1. Открой TextEdit
2. Нажми Right Option + H несколько раз быстро
3. Отпусти Right Option
4. Нажми A

**Ожидаемый результат:** буква `a` (НЕ символ `≈`) ✅

### Полное тестирование

Используй **`TESTING_CHECKLIST.md`** — 10 тестов с подробными инструкциями.

### Логи в Console.app

```
1. Открой Console.app
2. Фильтр: "hypetype"
3. Печатай символы и смотри логи:

✅ Правильные логи:
🔵 Right Option НАЖАТ
⌨️ KeyDown (H) | [R⌥=ON]
🔵 Right Option ОТПУЩЕН

⚠️ Если десинхронизация:
⚠️ ДЕСИНХРОНИЗАЦИЯ! Синхронизируем...  ← Это нормально!
```

## 🆘 Поддержка

### Если залипание всё ещё происходит

1. **Включи логи:** Меню → 🔍 Отладочные логи
2. **Воспроизведи баг**
3. **Собери информацию:**
   - Логи из Console.app (фильтр "hypetype")
   - Точная последовательность действий
   - macOS версия
   - Запущенные приложения (Alfred, BTT, etc.)
4. **Создай issue:** https://github.com/Simbaruzz/hypetype/issues

### Экстренный сброс

**3 способа:**

1. Меню → `🔄 Сбросить состояние` (⌘R)
2. Меню → Выкл/Вкл `Виртуализация`
3. Перезапустить приложение
