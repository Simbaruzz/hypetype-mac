# 📝 Методы вставки символов в HypeType

## Автоматический выбор метода

HypeType автоматически выбирает оптимальный метод вставки в зависимости от типа символа:

### 🚀 Прямой ввод (Unicode Events)

**Используется для:** 99% символов (→, –, «, », ×, ÷, €, ₽, и т.д.)

**Преимущества:**
- ⚡️ Очень быстро (30ms задержка)
- 🧹 Не трогает буфер обмена
- ✅ Не засоряет историю буфера (Raycast, Paste, etc.)
- 🎯 Точно — нет артефактов

**Как работает:**
```swift
// Генерируем CGEvent с Unicode строкой
keyDownEvent.keyboardSetUnicodeString(...)
keyDownEvent.post(tap: .cghidEventTap)
usleep(1000)  // 1ms между Down и Up
keyUpEvent.post(tap: .cghidEventTap)
```

---

### 📋 Через буфер обмена (Clipboard)

**Используется для:** 
- Эмодзи (😀, 🎉, 💡, etc.)
- Специальные символы > U+FFFF
- Пробелы (технические ограничения прямого метода)

**Недостатки:**
- 🐢 Медленнее (~80ms)
- ⚠️ Может попасть в историю буфера
- 🔄 Требует сохранения/восстановления буфера

**Оптимизация:**
- Буфер восстанавливается **МОМЕНТАЛЬНО** через `DispatchQueue.main.async`
- Минимизирует время когда символ в буфере
- Уменьшает вероятность попадания в историю

**Как работает:**
```swift
// Сохраняем буфер
let saved = pasteboard.string(forType: .string)

// Вставляем символ
pasteboard.setString(symbol, forType: .string)
simulateCommandV()  // Cmd+V

// МОМЕНТАЛЬНО восстанавливаем
DispatchQueue.main.async {
    pasteboard.setString(saved, forType: .string)
}
```

## Логика выбора метода

```swift
func insertSymbol(_ symbol: String) {
    if symbol.unicodeScalars.contains(where: { $0.value > 0xFFFF }) {
        // Эмодзи или специальный символ > U+FFFF
        insertViaClipboard(symbol)
    } else if symbol.isWhitespace {
        // Пробелы
        insertViaClipboard(symbol)
    } else {
        // ВСЁ ОСТАЛЬНОЕ - прямой ввод
        insertDirect(symbol)
    }
}
```

## Почему НЕТ настройки в UI?

**Решение:** Автоматический выбор метода — лучше чем ручная настройка.

**Причины:**
1. ✅ Пользователю не нужно думать о технических деталях
2. ✅ Оптимальная производительность для каждого символа
3. ✅ Минимум проблем с историей буфера обмена
4. ✅ "Просто работает" — философия macOS

**Прошлая проблема:**
- Раньше был toggle "Использовать буфер обмена"
- Пользователи не понимали что выбрать
- Либо медленная вставка, либо засорение истории

**Текущее решение:**
- Автоматически выбираем оптимальный метод
- Быстро + чисто для 95% символов
- Эмодзи работают (через clipboard когда нужно)

## Для разработчиков

### Добавление нового символа

Просто добавьте в `keymap.json` — HypeType автоматически выберет правильный метод:

```json
{
  "0x29": {
    "normal": "→",
    "shift": "←"
  }
}
```

### Отладка

Чтобы понять какой метод используется, добавьте print:

```swift
func insertDirect(_ symbol: String) {
    if symbol.unicodeScalars.contains(where: { $0.value > 0xFFFF }) {
        print("🔄 Clipboard метод для: \(symbol)")
        insertViaClipboard(symbol)
        return
    }
    
    print("⚡️ Прямой метод для: \(symbol)")
    // ...
}
```

## FAQ

**Q: Можно ли полностью избежать использования буфера?**  
A: Нет, для эмодзи нет другого способа. macOS API `keyboardSetUnicodeString` не поддерживает символы > U+FFFF.

**Q: Почему пробелы через clipboard?**  
A: Технические ограничения прямого метода — пробелы вставляются нестабильно.

**Q: Как минимизировать попадание в историю буфера?**  
A: 
1. Используем прямой метод по умолчанию
2. Восстанавливаем буфер моментально
3. Настройте Raycast/Paste игнорировать короткие элементы (см. `CLIPBOARD_HISTORY_FIX.md`)
