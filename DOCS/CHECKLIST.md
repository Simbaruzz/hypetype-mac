## ⚙️ Шаг 3: Настройка Info.plist

Кликните на **Info.plist** в Project Navigator:

**Вариант A - Через GUI:**
1. Нажмите + для добавления ключа
2. Добавьте:
   - `Application is agent (UIElement)` = **YES** (Boolean)
   - `Privacy - Accessibility Usage Description` = **"HypeType требует разрешение для перехвата клавиш"**
   - `Privacy - AppleEvents Sending Usage Description` = **"HypeType нужен доступ для управления событиями"**

**Вариант B - Через исходный код (проще):**
1. Правый клик на Info.plist → **Open As** → **Source Code**
2. Замените содержимое на созданный мной Info.plist
3. Сохраните

- [ ] Info.plist настроен

---

## 🔐 Шаг 4: Signing & Capabilities

1. Выберите проект (синяя иконка "hypetype" вверху)
2. Выберите Target **"hypetype"**
3. Вкладка **"Signing & Capabilities"**

### 4.1 Signing
- [ ] Automatically manage signing: ✅ включено
- [ ] Team: выберите (или None для локальной разработки)
- [ ] Bundle Identifier: должен быть уникальным (например `com.vishnya.hypetype`)

### 4.2 Hardened Runtime
- [ ] Нажмите **"+ Capability"**
- [ ] Найдите и добавьте **"Hardened Runtime"**
- [ ] В секции Hardened Runtime включите:
  - [ ] ✅ Disable Library Validation
  - [ ] ✅ Allow Execution of JIT-compiled Code (опционально)

## 🏗️ Шаг 7: Первая компиляция

1. В Xcode выберите схему: **hypetype > My Mac**
2. Нажмите **Product → Clean Build Folder** (⌘⇧K)
3. Нажмите **Product → Build** (⌘B)

### Если есть ошибки:

- [ ] Проверьте Target Membership (Шаг 6)
- [ ] Убедитесь что все импорты на месте
- [ ] Смотрите TROUBLESHOOTING.md

### Если сборка успешна:
- [ ] ✅ Build Succeeded

---

## 🚀 Шаг 8: Первый запуск

1. Нажмите **Product → Run** (⌘R) или кнопку ▶

### Что должно произойти:

- [ ] Появится диалог с просьбой разрешить Accessibility
- [ ] Нажмите **"Открыть настройки"** (или откройте вручную)
- [ ] **Системные настройки** → **Конфиденциальность и безопасность** → **Универсальный доступ**
- [ ] Найдите **"Xcode"** или **"hypetype"** и включите ✅
- [ ] Закройте приложение в Xcode (⏹️)
- [ ] Запустите снова (▶)

### После разрешения:

- [ ] Иконка клавиатуры появилась в menu bar (правый верхний угол)
- [ ] Нет окна приложения (если окно есть - проблема с LSUIElement)
- [ ] Клик по иконке открывает меню с пунктами:
  - Включено ✓
  - Вставка через буфер обмена ✓
  - Выход

## 🧪 Шаг 9: Тестирование в Console

1. Откройте **Console.app** (/Applications/Utilities/)
2. Нажмите **Start** вверху
3. В поиске введите: `hypetype`
4. Нажмите на иконку в menu bar

### Должны появиться логи:

- [ ] `✅ Event Tap запущен`
- [ ] `🎯 Тестовые маппинги загружены: 4 символов`

### Проверка Right Option:

1. Нажмите **правый** Option
2. В Console должно появиться:
   - [ ] `🔵 Right Option нажат`

3. Отпустите правый Option:
   - [ ] `🔵 Right Option отпущен`

4. Нажмите **левый** Option:
   - [ ] Ничего не должно произойти (это правильно!)
