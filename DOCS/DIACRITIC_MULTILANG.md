# 🌍 Многоязычная диакритика в hypetype

## Что изменилось?

Теперь диакритика работает с **любой раскладкой клавиатуры**!

### Было (только английский):
```
ROption+Shift+/ → ́ (acute)
Нажимаете 'o' → получаете 'ó'
```

Но в русской раскладке на той же клавише — буква `щ`  
❌ **НЕ работало**: нельзя было сделать `щ́`

### Стало (любой язык):
```
ROption+Shift+/ → ́ (acute)
Нажимаете 'o' в английской → 'ó'
Нажимаете 'я' в русской → 'я́'
Нажимаете 'ü' в немецкой → 'ǘ'
```

✅ **Работает** с любой раскладкой!

---

## Как это работает технически?

### Старый способ (хардкод):
```swift
let keyMap: [Int: (normal: String, shift: String)] = [
    0x00: ("a", "A"),  // Всегда английская 'a'
    0x1F: ("o", "O"),  // Всегда английская 'o'
    // и т.д.
]
```

**Проблема**: Игнорирует текущую раскладку.

### Новый способ (TISInputSource):
```swift
func getCharacterFromKeyCode(_ keyCode: Int, shift: Bool) -> String? {
    // 1. Получаем ТЕКУЩУЮ раскладку
    let inputSource = TISCopyCurrentKeyboardInputSource()
    
    // 2. Получаем layout data
    let layoutData = TISGetInputSourceProperty(inputSource, kTISPropertyUnicodeKeyLayoutData)
    
    // 3. Транслируем keyCode → символ с учётом раскладки
    UCKeyTranslate(layout, keyCode, modifiers, ...)
    
    // Результат: символ из ТЕКУЩЕЙ раскладки!
}
```

**Преимущество**: Автоматически определяет текущую раскладку.

## Технические детали

### API macOS:

**TISInputSource** — это Text Input Source API от Apple.

```swift
// Получаем текущую раскладку
TISCopyCurrentKeyboardInputSource() -> TISInputSource?

// Получаем layout data (карту keyCode → символ)
TISGetInputSourceProperty(inputSource, kTISPropertyUnicodeKeyLayoutData) -> CFData?

// Транслируем keyCode в символ
UCKeyTranslate(
    layout,           // Раскладка
    keyCode,          // Код клавиши
    action,           // keyDown/keyUp
    modifiers,        // Shift, Cmd, и т.д.
    keyboardType,     // Тип клавиатуры
    options,          // Флаги
    deadKeyState,     // Состояние dead keys
    maxLength,        // Размер буфера
    actualLength,     // Фактическая длина
    unicodeString     // Результат
) -> OSStatus
```

### Поддержка dead keys:

Флаг `kUCKeyTranslateNoDeadKeysMask` отключает обработку dead keys (например, `^` + `e` = `ê`).

Мы используем этот флаг, потому что реализуем **свою** логику диакритики.

### Модификаторы:

```swift
var modifierKeyState: UInt32 = shift ? UInt32(shiftKey >> 8) : 0
```

Передаём Shift если нажат, иначе 0.

2. `ROption+Shift+/` → `́` (acute)

### Тест 2: Русский

2. `ROption+Shift+/` → `́` (acute)
3. Нажмите `я`
4. ✅ Должно получиться: **я́**

### Тест 3: Динамическая смена
1. `ROption+Shift+/` → `́` (acute)
2. **Переключите раскладку** (Cmd+Space)
3. Нажмите `e` (английский) или `я` (русский)
4. ✅ Должно работать с **новой раскладкой**!

## Известные ограничения

### 1. Dead keys игнорируются
Некоторые раскладки используют dead keys (например, французская `^` + `e` = `ê`).

Мы их игнорируем флагом `kUCKeyTranslateNoDeadKeysMask`, потому что реализуем свою диакритику.

### 2. Compose-последовательности
Некоторые символы требуют нескольких нажатий (compose sequences).

Наш метод возвращает **первый символ** из последовательности.

## Кодировка и нормализация

### NFC (Canonical Composition)
```swift
func normalizeString(_ str: String) -> String {
    return str.precomposedStringWithCanonicalMapping
}
```

Склеивает базовый символ + диакритику в единый Unicode-символ (если существует).

**Примеры:**
- `e` + `́` → `é` (U+00E9, один символ)
- `я` + `́` → `я́` (U+044F + U+0301, два символа — нет готового)
- `o` + `̈` → `ö` (U+00F6, один символ)

## Дальнейшие улучшения

### 1. Кэширование раскладки
Сейчас мы получаем раскладку **каждый раз**.

Можно кэшировать и обновлять при смене:
```swift
NotificationCenter.default.addObserver(
    forName: NSTextInputContext.keyboardSelectionDidChangeNotification,
    object: nil,
    queue: .main
) { _ in
    // Обновить кэш раскладки
}
```

### 2. Fallback для неизвестных keyCode
Если `UCKeyTranslate` не вернул символ — можно использовать старый хардкод-маппинг как fallback.

### 3. Визуализация в HUD
Показывать не только диакритику, но и **пример** с текущей раскладкой:
```
┌─────────┐
│  ́       │
│ (a → á) │  ← Показать пример
└─────────┘
```
