# 🐛 Отладка диакритики

## Что было исправлено:

### 1. **Проблема с получением символа**
- ❌ **Было**: Пытались получить символ через `event.characters` (не существует в CGEvent)
- ✅ **Стало**: Используем маппинг `keyCode → символ` через метод `getCharacterFromKeyCode()`

### 2. **Проблема с логикой перехвата**
- ❌ **Было**: Проверяли диакритику ПОСЛЕ проверки Right Option
- ✅ **Стало**: Проверяем диакритику В блоке `guard !currentRightOptionPressed`

### 3. **Проблема с зависанием окна**
- ❌ **Было**: Анимации через `NSAnimationContext` могли блокировать поток
- ✅ **Стало**: 
  - Упрощённое скрытие через `orderOut()` + `close()`
  - `window.level = .statusBar` вместо `.floating`
  - Добавлен `collectionBehavior` для надёжности

### 4. **Проблема с отменой режима**
- ❌ **Было**: `cancelDiacriticMode()` мог вызываться несколько раз
- ✅ **Стало**: Добавлена проверка `guard isDiacriticMode` в начале метода

## Как тестировать:

### Тест 1: Базовая диакритика
```
1. ROption+Shift+; (умлаут ̈)
   → Должно появиться окно "̈ Введите букву..."
   
2. Нажмите 'o' (БЕЗ Right Option)
   → Должно появиться: ö
   → Окно должно исчезнуть
   → Программа должна продолжить работать
```

### Тест 2: Таймаут
```
1. ROption+Shift+; (умлаут ̈)
   → Окно появилось
   
2. Ждите 5 секунд, НЕ нажимая ничего
   → Через 5 сек окно должно исчезнуть
   → В консоли: "⏱️ Таймаут диакритики"
   → Программа должна продолжить работать
```

### Тест 3: Отмена через другой маппинг
```
1. ROption+Shift+; (умлаут ̈)
   → Окно появилось
   
2. ROption+E (€)
   → Должно вставиться: €
   → Окно должно исчезнуть
   → Программа должна продолжить работать
```

### Если что-то не так:

#### Окно не появляется:
```
✨ Режим диакритики: ̈
⚠️ Нет "🎨 DiacriticIndicatorWindow.show()"
```
→ Проблема с `DispatchQueue.main.async`

#### Окно зависло:
```
✨ Режим диакритики: ̈
🎨 DiacriticIndicatorWindow.show() начало
⏱️ Таймаут диакритики
🚫 cancelDiacriticMode: начало
❌ Режим диакритики отменён
🔄 Скрываю индикатор...
⚠️ НЕТ "🎨 DiacriticIndicatorWindow.hide()"
```
→ Проблема с методом `hide()`

#### Символ не вставляется:
```
✨ Режим диакритики: ̈
⚠️ Не удалось получить символ, отменяем режим
```
→ `getCharacterFromKeyCode()` не нашёл символ для keyCode
→ Нужно добавить этот keyCode в маппинг
