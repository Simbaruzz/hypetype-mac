# 🔧 Решение проблем HypeType MVP

## 🚨 Ошибки компиляции

### "Cannot find 'EventTapManager' in scope"

**Причина:** Файл не добавлен в Target

**Решение:**
1. Выберите `EventTapManager.swift` в Project Navigator
2. Откройте File Inspector (правая панель, иконка документа)
3. В разделе **Target Membership** убедитесь что галочка у "hypetype" стоит

### "Cannot find 'SettingsManager' in scope"

**Решение:** То же самое - проверьте Target Membership для `SettingsManager.swift`

### "Cannot find type 'CGEvent' in scope"

**Причина:** Не хватает импорта

**Решение:** Добавьте в начало файла:
```swift
import Cocoa
import Carbon
```

### "Use of unresolved identifier 'kAXTrustedCheckOptionPrompt'"

**Причина:** Нужен импорт ApplicationServices

**Решение:** В `hypetypeApp.swift` должно быть:
```swift
import SwiftUI
import ServiceManagement
```

И Xcode автоматически подтянет ApplicationServices через Cocoa.

## ⚙️ Проблемы запуска

### Приложение запускается, но иконки нет в menu bar

**Причина 1:** LSUIElement не установлен

**Решение:**
1. Откройте Info.plist в Project Navigator
2. Правый клик → Open As → Source Code
3. Убедитесь что есть:
```xml
<key>LSUIElement</key>
<true/>
```

**Причина 2:** Приложение крашится при запуске

**Решение:** Смотрите логи в Console.app

### Окно открывается вместо menu bar

**Причина:** Не удален WindowGroup или LSUIElement = false

**Решение:** В `hypetypeApp.swift` должно быть:
```swift
var body: some Scene {
    Settings {
        SettingsView()
    }
}
```

Не должно быть `WindowGroup`.

## 🔐 Проблемы с разрешениями

### Диалог разрешений не появляется

**Решение 1:** Принудительно сбросить разрешения
```bash
tccutil reset Accessibility com.yourname.hypetype
```
(Замените `com.yourname.hypetype` на ваш Bundle ID)

**Решение 2:** Проверить Info.plist
Убедитесь что есть:
```xml
<key>NSAccessibilityUsageDescription</key>
<string>HypeType требует разрешение для перехвата клавиш</string>
```

### Разрешение дано, но Event Tap не запускается

**Симптом:** В Console пишет "❌ Ошибка: не удалось создать Event Tap"

**Решение:**
1. Откройте **Системные настройки**
2. **Конфиденциальность и безопасность**
3. **Универсальный доступ**
4. Найдите "hypetype" (или Xcode при отладке)
5. **Удалите** его из списка
6. Перезапустите приложение
7. Разрешите заново

## ⌨️ Проблемы с перехватом клавиш

### Левый Option тоже срабатывает

**Причина:** Ошибка в определении правого Option

**Проверка:** Откройте Console.app и следите за логами.
При нажатии **правого** Option должно быть: `🔵 Right Option нажат`
При нажатии **левого** Option ничего не должно быть.

**Решение:** В `EventTapManager.swift` проверьте:
```swift
if keyCode == 0x3D { // Right Option = 61
    rightOptionPressed = flags.contains(.maskAlternate)
}
```

### Символы не вставляются

**Симптом:** В Console пишет "⌨️ Перехвачено", но ничего не вставляется

**Причина 1:** Неправильный метод вставки для конкретного приложения

**Решение:** Переключите метод в menu bar:
- Попробуйте **Вставка через буфер обмена** (ON)
- Если не работает, попробуйте (OFF) - прямой ввод

**Причина 2:** Приложение не поддерживает вставку

**Проверка:** Попробуйте в TextEdit - должно работать.

## 🎯 Проблемы в конкретных приложениях

### Figma

**Проблема:** Символы вставляются как ???

**Решение:** Figma иногда требует UTF-8 шрифт. Проверьте что используется шрифт с поддержкой типографских символов (SF Pro, Arial, etc.)

**Проблема:** Ничего не происходит

**Решение:** 
1. Убедитесь что текстовый блок активен (курсор мигает)
2. Используйте метод clipboard (галочка в menu bar)

### Adobe Photoshop / Illustrator

**Проблема:** Вставляется оригинальная клавиша вместо символа

**Причина:** Adobe перехватывает события раньше

**Решение:** 
1. Переключитесь на clipboard метод
2. Если не помогает - это ограничение Adobe, они могут перехватывать события раньше

### Terminal / iTerm

**Проблема:** Не работает совсем

**Причина:** Терминалы часто перехватывают Option для собственных целей

**Решение:** В настройках терминала отключите "Use Option as Meta key"

## 🆘 Все еще не работает?

Соберите информацию:

1. **Версия macOS:**
   ```bash
   sw_vers
   ```

2. **Bundle ID приложения:**
   Посмотрите в Project settings → General → Bundle Identifier

3. **Логи из Console:**
   Скопируйте все сообщения с "hypetype"

4. **Где тестируете:**
   - TextEdit (должно работать)
   - Figma (приоритет)
   - Adobe app (приоритет)

5. **Что именно не работает:**
   - Иконка не появляется?
   - Right Option не детектится?
   - Символы не вставляются?
   - Другое?

С этой информацией можно найти проблему! 🔍
